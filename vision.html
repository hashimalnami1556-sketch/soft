Google Vision API

تطبيق لتحويل الخط السيء إلى نص واضح

ارفع صورة بخط يد غير واضح وسنستخدم Google Vision API لاستخراج النص ثم عرضه بشكل مرتب.

يشترط تشغيل خادم محلي يحمي مفتاح Google Vision API ويستقبل الطلبات على المسار /api/vision. هذا يمنع مشاكل الحظر عبر المتصفح ويحافظ على أمان المفتاح.

ستظهر المعاينة هنا بعد اختيار صورة.

نصائح لتحسين الدقة

  • التقط الصورة بإضاءة جيدة ومن دون ظلال.
  • اجعل الورقة مستقيمة قدر الإمكان.
  • تأكد من وضوح الحروف وعدم وجود ضبابية.
